# Dental Technical Support Skill (이노쓰리디 맞춤)

> **스킬 선택 기준** — 이 스킬이 담당하는 것: 고객·딜러에게 나가는 기술 대응.
> 아래에 해당하면 이 스킬 대신 그쪽을 쓴다: `inno3d-clinical-dev-bridge`(개발팀 전달본) · `xlsx`(실제 엑셀 파일 생성) · `dental-education-training`(커리큘럼)

## 제품 컨텍스트
- Densflo Scan: 듀얼 프로젝터 방식, IDT-1000. [확인필요] <5μm 정확도는 측정규격(ISO 12836 등) 미확보 — 대외 문서에 단정적으로 쓰지 말 것
- Densflo Codi: 환자 상담 SW, 구글 폼 연동 가능
- 담당: 김민선 과장 / 이노쓰리디
- 확정(2026-09-16): 주소 1420호 / FDA 등록완료(Reg.No.3044774668, 승인아님) / 판매가 단품900만·세트1250만

## 1. 문제 분류 체계

```
Level 1 (사용자 해결) — 재시작, 기본 캘리브레이션, 렌즈 세정
Level 2 (원격 지원)  — SW 설정, 네트워크, 데이터 전송 오류
Level 3 (현장/회수)  — 하드웨어 손상, 센서/렌즈 문제
```

## 3. 임상 테스트 평가 프레임워크

### 현재 진행 중인 임상 테스트
- 목표: 15~20케이스 취합 후 영업 본격화
- 도구: Densflow_v6 임상 평가 스프레드시트
- KPI 기준 5개:
  - 정확도 ≤ 0.15mm
  - 리메이크율 ≤ 10%
  - 전체 재작업 비율 ≤ 20%
  - 환자 만족도 ≥ 4.0/5.0
  - 조정 없이 세팅 완료율 ≥ 50%

### 임상 평가 항목 (케이스별, 실제 구글폼 선택지 기준 — 2026-09-16 확정)
- 보철 종류: Crown/Bridge/Inlay/Implant/PMMA
- 내면 적합도: 양호/빡빡함/헐거움/재제작필요
- 마진 적합도: 양호/마진 짧음/오버 마진/재제작필요
- 리메이크 여부: Y/N
- 환자 만족도: 1~5점
- 술자 코멘트
- [주의] "적합/양호/불량" 3단계 척도는 실제 폼과 다른 구버전 표기이니 사용 금지

## 5. 스캔 중 음악 (Medit Link 연동 참조)

- Densflo: 사용자 정의 사운드 추가 가능 (Medit Link 방식 참고)
- 이재윤 연구원 제공 원본 파일 → AI(Suno) 생성 대체본 제작 완료
- 형식: 30초 루프 MP3, 저작권 없음, 밝고 부드러운 피아노
