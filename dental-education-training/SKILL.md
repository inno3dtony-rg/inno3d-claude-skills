# Dental Education & Training Skill (이노쓰리디 맞춤)

> **스킬 선택 기준** — 이 스킬이 담당하는 것: 교육 과정·교재 설계.
> 아래에 해당하면 이 스킬 대신 그쪽을 쓴다: `inno3d-meeting-processing`(회의록) · `dental-technical-support`(개별 장애 대응)

## 컨텍스트
- 담당: 김민선 과장 (교육 직접 담당)
- 제품: Densflo Scan + Codi
- 팀: 2인 (+ 치위생사 채용 예정)
- 확정(2026-09-16): 양희중 이사 10월 중순 퇴사 예정(전언) → 이후 마케팅·기획팀 1인 체제. 대구보건대 특강 2026.09.22

## 1. 교육 대상별 접근법

| 대상 | 레벨 | 핵심 니즈 | 포맷 |
|------|------|----------|------|
| 치과 원장 | 의사결정자 | ROI·임상 적용·간결 요약 | 1~2페이지, 영상 |
| 치과위생사·스탭 | 실무 사용자 | 단계별 조작법, 트러블슈팅 | 매뉴얼, 체크리스트 |
| 딜러·영업담당 | 세일즈 교육 | 제품 지식·경쟁사 비교·데모 방법 | 슬라이드, Q&A |
| 치기공사 | 기술 전문가 | 스캔 데이터 처리, SW 연동 | 기술 가이드 |
| 일본 딜러 | 현지화 교육 | 일본어 자료, PMDA 규정 이해 | 일본어 매뉴얼 |

## 2. Densflo 교육 커리큘럼 표준 (5모듈)

```
모듈 1: 제품 개요 (15분)
  - 구강 스캐너란? vs 기존 인상재
  - Densflo Scan 핵심 스펙·차별점
  - Densflo Codi 환자 상담 SW 개요

모듈 2: Densflo Scan 기본 조작 (30분)
  - 장비 셋업, 위생 관리 (팁 교체)
  - 스캔 시작~완료 절차
  - 스캔 중 음악 설정 방법

모듈 3: Densflo Codi 활용 (30분)
  - 3D 상담 화면 사용법
  - 리포트 자동 생성
  - 기공주문 연동 방법

모듈 4: 트러블슈팅 (20분)
  - 스캔 품질 저하 시 대처
  - 코너 부위 처리법 (현재 알고리즘 최적화 중)
  - 기술 지원 연락 방법 (02-6952-0693)

모듈 5: 임상 적용 실습 (30분)
  - 케이스별 워크플로우 (보철·교정·임플란트)
  - 임상 평가 스프레드시트 기입 방법
  - 체크리스트 기반 평가
```

## 3. 회의록·내부 문서 작성 기준

### 회의록 출력 구조
```
① 회의 기본 정보 (일시·장소·참석자)
② 안건 요약
③ 주요 결정 사항
④ 액션 아이템 (담당자·기한·출처)
⑤ 미결 사항
⑥ 비고
```

### 액션 아이템 표 포맷
| No | 내용 | 담당자 | 기한 | 출처 |
|----|------|--------|------|------|

### 이노쓰리디 회의 특이사항
- 녹취 + 메모 교차 검증 원칙 적용
- 최종본: 수령 후 3 영업일 내 이의 제기 가능
- 주요 상대: 최 대표 (소비자가·전략 결정), 양희중 이사
