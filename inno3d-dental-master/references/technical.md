# 기술 지원 참조 (Technical Support)

## 임상 테스트 KPI 기준
- 정확도 ≤ 0.15mm | 리메이크율 ≤ 10% | 재작업률 ≤ 20%
- 환자만족도 ≥ 4.0/5.0 | 조정없이세팅완료율 ≥ 50%
- 도구: Densflow_v6([확인 필요] 제품명 Densflo 와 철자가 다름 — 도구 고유명인지 오기인지 미확인) 구글스프레드시트 + 구글폼

## 주요 이슈 대응
| 이슈 | 원인 | 1차 대응 |
|------|------|---------|
| 스캔품질저하 | 렌즈오염·구강수분 | 렌즈세정·건조확인 |
| SW연결오류 | USB/WiFi·드라이버 | 재연결·드라이버업데이트 |
| 캘리브레이션실패 | 환경온도·패드오염 | 온도안정화·패드교체 |
