# 이노쓰리디 회의록 처리 스킬

## 컨텍스트
- 담당: 김민선 과장 (CLOVA Note 전사본 업로드 → Claude가 정리 → docx 산출)
- 처리 대상: 팀 회의, 딜러 미팅, 임상 협력 통화, TF 회의, 채용 레퍼런스체크 등 성격이 다양함

## 1. 문서 유형 자동 판별 (가장 먼저 할 것)
전사본 내용을 보고 아래 중 어느 유형인지 먼저 판단한다.
| 신호 | 유형 | 처리 |
|---|---|---|
| 여러 안건, 결정사항 다수 | 일반 회의록 | 표준 템플릿(아래) |
| 1:1 통화, 단일 주제 | 통화기록 | 표준 템플릿 축소판 |
| **채용 후보자 레퍼런스체크** | 특이 케이스 | 회의록이 아니라 **내부 채용 검토 메모**로 재구성 — 후보자명·개인정보 전부 익명화, 연령·성별 기반 판단 금지 문구 명시 |

## 2. 표준 회의록 구조 (house template)
```
[개요 kvTable] 일시 / 장소(or 통화) / 참석자 / 작성자
[3줄 요약]
[안건별 본문] — 안건마다 소제목, 핵심 발언은 ★ 표시
[액션 아이템 표] 담당자 | 내용 | 기한 | 출처
  → 긴급·HOT 항목은 표 행 노란색 강조
[미결 사항] — [확인 필요]/[전언]/[변동] 태그 사용
[비고]
[작성 주의] 문구
[3영업일 이의제기 안내 문구] — 모든 회의록 하단 필수
```

## 3. 반복 등장 리스크 — 매번 자동 점검
전사본에서 아래가 언급되면 **정정하거나 경고 박스를 넣는다.**
- FDA를 "인증/승인/허가"로 표현 → 등록(리스팅)으로 정정, 빨간 경고박스 추가(누적 발생 횟수 명시)
- 딜러 공급가를 구두로 확정하듯 말함 → 재판매가격유지(MAP) 리스크 플래그
- "레뉴메디칼" 언급 시 → 현재 레뉴메디칼 법인이 아니라 퇴사 예정 임원의 향후 법인을 가리킬 가능성 — 문맥 확인 후 명시
- 딜러 실적 수치(NEO·Medit 등) → 출처 재확인 전 단정 표현 금지

## 4. 핵심 인물 호칭 규칙
양희중 이사(직속상관, 카카오톡 브리핑은 결론 먼저) / 최병환 대표 / 정상호 사장 / 안혜정 책임(플랫폼팀 리더, TF 주재) — 직함 정확히 표기, 반말·약칭 금지

## 5. 개인정보 처리
후보자명·환자명·타사 내부사정은 문서에서 **익명화 또는 제외**. 채용 판단 관련 발언이 있으면 연령·성별 기준 판단으로 읽히지 않도록 문구를 순화하거나 삭제.
