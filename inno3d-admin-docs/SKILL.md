# 이노쓰리디 다우오피스 행정문서 스킬

## 회사 컨텍스트 (2026-09-16 확정)
- 기안자: 김민선 과장 / 마케팅·기획팀
- 결재라인: 김민선(기안) → **양희중 이사**(승인) → **정상호 사장** → (지원사) **펨트론 조항석 전무**(최종 승인)
- 참조: 김재우 부사장 / 임상 건은 안혜정 책임 추가 참조
- 지출 자금: 지원사 펨트론이 지급하는 구조 — 조항석 전무의 승인이 사실상 최종 관문

## 1. 형식 절대 규칙
- **특수문자·표 없는 산문 형식** (다우오피스 입력창에 그대로 붙여넣을 수 있게)
- 본문 구조: 도입문장 → 번호목록(1.제목 2.일시 3.장소 4.내용 5.금액 6.첨부) → 참조란
- **추진배경·목적·기대효과 필수 명시** — 펨트론 조항석 전무 승인의 실질적 근거가 되는 부분이므로 생략 금지
- 헤더: 기안자·소속·기안일(YYYY-MM-DD(요일))·문서번호(다우오피스 자동채번이라 임의 생성 금지)

## 2. 지출결의서 — 금액 처리 규칙
- 원천징수 3.3%는 **케이스별로 개별 계산 후 차감** (총액 일괄 계산 금지)
- 금액은 항상 **순지급액(세후)** 기준으로 라인아이템·합계 표기 — 총지급액(세전) 병기 금지
- 면세 사업자(예: 오랄디자인센터) → 계산서 / 과세 거래 → 세금계산서, 증빙 종류 반드시 구분
- 증빙 수령: 관리팀 부재로 담당자가 개인 이메일로 수령 후 첨부하는 구조 — 전자계산서 수신 확인 절차 포함

## 3. 품의서 vs 지출결의서 구분
| 상황 | 문서 유형 |
|---|---|
| 아직 집행 전, 승인부터 받아야 함(구매·계약·행사) | 품의서 |
| 이미 발생한 비용을 정산·지급 요청 | 지출결의서 |
| 견적 확정 전 사전 승인이 필요한 건 | 품의서(반려 가능성 있으므로 견적 확보 후 작성 권장) |

## 4. 반복 확인 필요 항목 (매번 점검)
- 세션·회차 번호(예: "7~10회차")는 이전 기록과 연속성 확인 후 기재
- 지급 요청일·기안일이 실제 업무 흐름과 맞는지
- 환자 표기는 "케이스" 단위로만(개인정보 익명화 원칙, ways-of-working 참조)

## 5. 출력 형식
결론(승인 요청 요지) 먼저 제시 후, 다우오피스 입력용 전체 텍스트를 별도 블록으로 제공. 계산이 들어간 경우 입력값→산식→결과를 답변에서 먼저 검산해 보여준 뒤 결의서 본문에는 결과만 반영.

## 관련 스킬 연계
- 임상 관련 지출 → `dental-technical-support`
- 마케팅 관련 지출(배너·카탈로그) → `dental-marketing`
