# 임상→개발 언어 전환 스킬

> **스킬 선택 기준** — 이 스킬이 담당하는 것: 사내 개발팀 전달용 정량 지표.
> 아래에 해당하면 이 스킬 대신 그쪽을 쓴다: `dental-technical-support`(고객에게 나가는 답변)

## 역할 경계 (가장 중요 — 매번 지킬 것)
- 담당자(김민선 과장)의 역할은 **관찰을 개발팀이 쓸 수 있는 형태로 구조화**하는 것까지.
- **파라미터를 제안하거나 기능정의서를 대신 쓰지 않는다** — 이건 사내 개발 주관(이상욱 이사·김병기 책임·류완석 이사)의 몫.
- 애매하면 "이건 관찰 기록이지 스펙 제안이 아니다"를 스스로 점검한다.

## 1. 현장 표현 → 지표 ID 매핑 (검증된 용어사전, 확장 가능)
| 현장에서 하는 말 | 개발 용어 | 지표 ID |
|---|---|---|
| 우둘투둘하다 | 표면 법선 노이즈 / 계단현상 | M17 |
| 끊긴다 | 트래킹 로스 → 재정합 실패 | M13 |
| 오정합(이중 표면·단차) | 정합 오차 누적 / 드리프트 | M03 |
| 섬세함이 부족하다 | 과도한 스무딩 / 곡률 특징 손실 | M04 |
| 메탈이 안 찍힌다 | 고반사 표면 획득 실패 | M15 |
| 작은 글씨가 읽힌다(각인 등) | 미세 형상 재현 한계 | M16 |
| 혀·볼이 지워졌다 다시 생긴다 | 세그멘테이션 재유입 | M18 |
| 팁을 못 알아본다 | 팁 감지 오인식 | M19 |
| 느리다(화면 지연) | 프레임레이트 저하 / 지연 | M10 |
| 보철이 안 맞는다 | 최종 데이터 형상 오차 | M07 |
| 전악이 틀어진다 | 전역 정합 드리프트(풀아치) | M08 |

새 표현이 나오면 이 표를 확장하고, 근거 등급을 반드시 매긴다.

## 2. 근거 등급 4단계 (섞지 말 것)
- **[견적]** — 외주·구매 견적서에 명시된 값
- **[문헌]** — 논문·규격 원문 대조 완료 (예: ISO 12836, 학술지 인용 시 저자·연도 정확히)
- **[제안]** — 당사 제안값, 아직 협의·승인 전
- **[미정]** — 그라운드 트루스 미확보, 향후 측정 필요

## 3. 산출물 표준 구조 (엑셀/문서 공통)
```
1_이슈기록: 현장 기록(노란칸) + 지표ID 선택(K열) → 지표명·단위·측정법·목표값 자동 표시(회색칸, 수정금지)
2_용어사전: 현장표현 ↔ 개발용어 ↔ 지표ID, "확정" 여부 컬럼 필수
3_측정기준: 지표 마스터 목록, 근거등급 표기
```
수식은 INDEX/MATCH + IFERROR 기본, 초록칸=자동계산(잠금), 개발팀 입력 후 충족/미달 자동판정.

## 4. 절대 금지
- 근거 등급 표기 없이 목표값을 단정적으로 제시하지 않는다
- 출처(논문 저자·발행연도, 견적서 항목명)를 생략하지 않는다
- 임상 관찰 하나를 여러 지표에 중복 배정해 혼란 주지 않는다 — 가장 가까운 지표 1개 우선, 필요 시 2개까지만

## 관련 스킬 연계
- 회의록·통화 전사 → `inno3d-meeting-processing`
- 완제품 기술지원 이슈(고객 대응용) → `dental-technical-support`
